PRIVACY NODE

LOCAL FIRST.

ArchDeck is designed to process most launcher, notification, keyboard and visualization data on the device.

ARCHDECK // PRIVACY SUMMARYUSER CONTROLLED
> notification.content  = processed on-device for LockDeck/badges
> keyboard.learning     = stored locally by ARCHKEY
> audio.visualization   = processed locally
> home_assistant        = connects only when configured by user
> album.art.lookup      = may use network access
> personal.data.sale    = no
> advertising.tracking  = none built into ArchDeck

Notification access

When enabled, ArchDeck uses Android notification-listener access to display notification counts and LockDeck event information. ArchDeck does not need to upload notification content to provide those features.

Media and audio

ARCHAMP can process audio information locally to drive visualizers and equalizer features. The Android permissions requested for audio features should be reviewed before use.

Home Assistant

If you configure a Home Assistant server, ArchDeck may connect to the server address you provide in order to show smart-home state and controls. Your server credentials should be treated as sensitive.

Network requests

Some optional features, such as online album-art lookup and configured Home Assistant access, require network connectivity.

Changes

This privacy page should be updated whenever ArchDeck adds a new data source, cloud service, analytics SDK or account system.
